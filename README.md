# 🍼 Baby Tracker — Feedback & Bug Reports

This is the public issue tracker for **Baby Tracker Watch** — a Samsung Galaxy Watch app for tracking your baby's feeding, sleep, activity, diapers, and more.

> **The app source code is not hosted here.** This repo exists solely for bug reports and feature requests.

---

## 📲 About the App

Baby Tracker Watch lets you log everything that matters in your baby's day — directly from your wrist.

- 🤱 **Feeding** — left breast, right breast, bottle, solids
- 🌙 **Sleep** — start/stop timer, duration tracking
- 🏃 **Activity** — tummy time, bath, walk, play
- 💧 **Diaper** — instant wet/dirty log
- 😢 **Hysterics** — crying session timer
- 📊 **Analytics** — last event and today's totals at a glance
- 👤 **Multiple children** — switch profiles on your phone, watch updates automatically
- 📱 **Phone companion** — 7-day charts, full history, record editing, and sync

Available on **Samsung Galaxy Watch** (Wear OS).

## 📋 Issue Labels

| Label | Meaning |
|---|---|
| `bug` | Something isn't working as expected |
| `feature-request` | A new capability or improvement |
| `watch` | Affects the Galaxy Watch app |
| `phone` | Affects the phone companion app |
| `sync` | Watch ↔ phone data sync |
| `analytics` | Charts, stats, or history screens |
| `ui` | Layout, design, or visual issue |
| `investigating` | We've seen it and are looking into it |
| `planned` | Confirmed, will be built |
| `wont-fix` | Out of scope or not reproducible |
